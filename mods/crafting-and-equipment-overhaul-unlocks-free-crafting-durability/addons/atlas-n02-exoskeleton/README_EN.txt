ATLAS N02 Exoskeleton Addon 1.0.0
Optional download for Crafting & Equipment Overhaul - Nexus Mod 86

INSTALL
Install Crafting & Equipment Overhaul 1.10.1 or a later compatible version.
Close DS2. Copy only ds2_atlas_exoskeleton_addon.asi beside DS2.exe. Done.
No extra INI or manually installed bin/data folder. Uses the main mod's x64 ASI loader.

APPEARANCE AND COMPATIBILITY
Gives the separately craftable ATLAS skeleton a graphite-black N02 appearance with
red accents, revised geometry and a matching rendered menu image. The main mod
retains ownership of stats, recipes and saved item identities. Normal skeletons
remain available. Chiral Boots Addon 1.0.0 is optional: either addon can be used
alone, or both together. The existing shoe-addon ASI does not need replacing.

REMOVE
Close DS2 and remove ds2_atlas_exoskeleton_addon.asi. Keep the main mod installed.
On the next start, ATLAS uses the main mod's normal skeleton appearance (gold by
default, depending on GoldSkeletonSkin). The ATLAS item and stats remain available.
Native saves are not rewritten. This describes removing the visual addon, not
removing the main mod's custom item definitions.

FIRST START / UPDATES
The addon automatically builds atlas_exoskeleton beside DS2.exe. Allow about
1.5 GB for its resource cache; the main mod and shoe addon may generate additional
caches. Original game archives are not replaced. Generated cache files may be
deleted while the game is closed and are rebuilt when needed.
Verified game build: DS2 PC 1.10.89.0. Main-mod content, recipe and stat updates
do not require addon updates while Addon API V1, Visual Router V1 and ATLAS item
identities remain stable. New game builds or conflicting resource mods may need
separate compatibility work.
