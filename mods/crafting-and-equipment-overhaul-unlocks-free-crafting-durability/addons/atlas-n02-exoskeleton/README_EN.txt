ATLAS N02 Exoskeleton Addon 1.0.1
Optional file for Crafting & Equipment Overhaul (Nexus mod 86)

Graphite-black N02 appearance, red accents and matching menu image for the ATLAS skeleton.

Install file: ds2_atlas_exoskeleton_addon.asi

INSTALL / UPDATE
Close DS2 and replace the ASI beside DS2.exe. Only that ASI needs installing.
No additional INI or manual bin/data folder is required. Keep Crafting & Equipment
Overhaul and its ASI loader installed. Main mod 1.10.1 does not need an update.
If using both visual addons, update BOTH Chiral Boots and N02 to 1.0.1.
N02 1.0.0 cannot cooperate with the new shoe build. Each 1.0.1 addon also works alone.

REMOVE
Close DS2 and remove this addon's ASI. With the main mod still installed, ATLAS
returns to the main mod's appearance on the next start. Item identities, recipes
and stats remain owned by the main mod; this addon does not edit save files.
Removing the main mod itself is a separate case and is not covered by this fallback.

COMPATIBILITY
Verified executable: DS2 PC 1.10.89.0. Normal Crafting content/stat updates do not
require rebuilding these addons while Addon API V1, Visual Router V1 and the ATLAS
item/resource contracts stay compatible. Arbitrary future game updates are not
guaranteed. Original game archives are not replaced. Resource caches are generated
automatically on first use; allow about 1.5 GB per generated visual cache.
Sam Overhaul's HideSpareShoes setting can hide boots on the boot clip.
