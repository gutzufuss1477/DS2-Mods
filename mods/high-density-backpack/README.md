# High Density Backpack

Equip up to 30 backpack modules and eight charms. Main version packs models neatly and hides excess visuals; optional Classic Overlap keeps the crowded look. Install one variant only.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/68)
