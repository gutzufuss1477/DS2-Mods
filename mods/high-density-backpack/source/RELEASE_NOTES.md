# High-Density Backpack Modules 1.1.0

Up to 30 functional modules with automatic placement, a separate visual layout that hides excess models, and eight accessory slots (two visible, six invisible).

Rendering now covers customization, cargo management and gameplay after loading an existing save. Extra charm selections are saved automatically in an installation-wide INI. Only unlocked, equipped charms contribute to the additional effect checks; native module-specific limits remain.

The release uses the user-validated Test5 logic unchanged. Local runtime and native-instruction regression checks pass. Actual effect magnitudes and every save/menu combination have not all been measured.

## Update

Close DS2, remove previous Backpack ASIs and copy the new ASI beside DS2.exe. Keep exactly one Backpack version active and preserve the existing charm INI. The ZIP contains one ASI only; a compatible external 64-bit ASI loader is required.

Supported game: DS2.exe v1.10.89.0.
