# Faster and longer Ziplines

Extend Zipline build and ride range to 600 m by default and travel at 2x speed. Range up to 1,000 m; speeds above the tested 4x setting are experimental.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/70)
