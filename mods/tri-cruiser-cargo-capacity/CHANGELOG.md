# Changelog

## v1.0.0

- Initial stable release.
- Raises Tri-Cruiser cargo capacity to a 320-unit target.
- Supports freely mixed S/M/L/XL cargo.
- Preserves native load/unload, driving and save/load behavior.
- Cyclically reuses valid native physical slot keys for overflow cargo.
- Removes all development probes, runtime diagnostics and experimental transform/ownership workarounds.
