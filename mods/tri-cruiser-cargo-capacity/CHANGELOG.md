# Changelog

## v1.1.0

- Updates the existing Tri-Cruiser Cargo Capacity mod; no separate accessory add-on is required.
- Keeps the full **320-unit cargo capacity** with 0, 1 or 2 mounted side accessories.
- Adds stable support for dual Battery Units and Anti-Gravity/side equipment while carrying cargo.
- Dual-accessory cargo uses the proven native one-side packing path without modifying the actual accessory state.
- Preserves loading, unloading, driving and save/load behavior.
- Removes all accessory-development telemetry and test status output from the release build.

## v1.0.0

- Initial stable release.
- Raises Tri-Cruiser cargo capacity to a 320-unit target.
- Supports freely mixed S/M/L/XL cargo.
- Preserves native load/unload, driving and save/load behavior.
- Cyclically reuses valid native physical slot keys for overflow cargo.
