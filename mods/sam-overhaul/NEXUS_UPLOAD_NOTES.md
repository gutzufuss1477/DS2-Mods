## Important compatibility notice for existing users

All three NEW options are OFF in the packaged INI: HideFootprints=0, GeneratorRange Enabled=0 and TimefallShelterRange Enabled=0. Enable them individually in the included config. Existing users upgrading from v1.0.0 should retain their customized INI and merge the new sections, rather than overwrite custom truck/movement/Autodrive values. Only one Sam Overhaul ASI version may remain in the game directory.

The support target is Steam DS2.exe 1.10.89.0 Windows x64. Epic Games Store and other game executable revisions have not been validated. The ASI requires an existing x64 ASI loader; none is bundled.

No Nexus upload or GitHub release has been performed by package generation.
