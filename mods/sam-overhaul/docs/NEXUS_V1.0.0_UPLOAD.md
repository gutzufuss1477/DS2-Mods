## Short description
Configurable all-in-one Sam QoL overhaul: hide cargo and spare shoes, freer monorail/zipline exits, backpack landing rolls, faster Autodrive, and longer-range/faster truck weapons.

## Changelog
- First public release.
- Cargo visibility controls for shoulder, hip, backpack and spare shoes.
- Expanded monorail and zipline dismount behaviour.
- Landing roll support with backpack/cargo.
- Configurable faster Autodrive activation.
- Independent tuning for Heavy MG, Mortar, Chiral Cannon and Missile Launcher.
- Chiral Cannon charge time configurable with tested 0.75-second default.
- Strict target-build/context validation and local diagnostics.
- Final build passes 105,704 Autodrive regression checks.
