# Release Smoke Test

1. Copy `SamStatsBooster.asi` and `SamStatsBooster.ini` beside the configured ASI loader.
2. Start DS2 and confirm `SamStatsBooster.log` reports `State: ACTIVE`.
3. Trigger one non-maxed category through its normal gameplay action.
4. Open Sam's Stats menu and confirm progress or a level change.
5. Save, restart the game and confirm the level remains.

A dedicated gameplay notification is not required for a pass. The Stats menu and stored-gain log are the authoritative checks.
