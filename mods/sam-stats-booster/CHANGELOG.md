# Changelog

## v1.0.0

- Released the configurable Sam Stats progression multiplier.
- Supports all 12 visible radar-chart categories with independent INI switches.
- Preserves DS2's normal eligibility checks, native storage, caps, thresholds, level effects, UI and save persistence.
- Set the release default multiplier to `5.0` and retained the supported range of `1.0` to `100.0`.
- Confirmed exact stored gains for all four Double-backed physical stats at `20.0x`.
- Confirmed exact stored gains for Lung Capacity, Melee Combat and Assault Rifles at `50.0x`.
- Confirmed rapid Lung Capacity progression to level 5 in Sam's Stats menu.
- Documented that the mod does not add or alter HUD level-up notifications.
- Preserved compatibility handling for Porter Grade Booster load order.

## v0.1.2-verify

- Added native before/after storage verification for the Q32 combat/weapon path and Q64 Lung Capacity path.
- Extended the Q32 and Q64 producer patch windows through their original mutator calls.

## v0.1.1-verify

- Added native before/after storage verification for Terrain Traversal, Carrying Capacity, Endurance and KO Resistance.

## v0.1.0-test

- Initial dedicated producer hooks and event counters.
