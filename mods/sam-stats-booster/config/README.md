# Configuration

Copy `SamStatsBooster.ini` beside `SamStatsBooster.asi` and restart the game after changing it.

- `Enabled=1` enables the mod.
- `Multiplier` accepts values from `1.0` to `100.0`.
- Each entry under `[Stats]` independently enables or disables one category.
- `StealthTakedown` is an internal thirteenth skill and remains disabled by default.

Recommended release range: `2.0` to `5.0`. A value such as `50.0` is useful for validation but can skip several visible level thresholds in a very short time.
