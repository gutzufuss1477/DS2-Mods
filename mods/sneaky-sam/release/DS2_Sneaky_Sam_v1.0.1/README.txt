Sneaky Sam v1.0.1
DEATH STRANDING 2: ON THE BEACH

Hides cargo attached to Sam's left/right shoulder and left/right hip while keeping
inventory, weight, condition and gameplay state unchanged.

Installation:
Copy DS2_SneakySam_v1.0.1.asi into the DS2 game / ASI loader directory.

Requires a working x64 ASI loader.
Validated for DS2.exe v1.10.89.0.

v1.0.1:
Rebuilt with the Microsoft Visual C++ toolchain and a standard Windows version
resource. Runtime relay memory now transitions from RW to RX and is never allocated
as RWX. Functional behaviour is unchanged from v1.0.0.
