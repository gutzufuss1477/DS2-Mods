# Changelog

## 1.0.0

- Initial public release.
- Configurable remaining material amount through `RemainingUnits`.
- Supports road construction and road stage-2 upgrades.
- Supports monorail construction.
- Supports mine construction and mine stage-2/stage-3 upgrades.
- Preserves existing online/other-player contributions by applying only the missing delta.
- Uses the game's native partial-container consumption and overflow handling.
- Automatically updates loaded supported infrastructure, including world/overview displays when the game refreshes them.
- Strict Steam v1.10.89.0 build and signature validation.
- Optional debug logging.
