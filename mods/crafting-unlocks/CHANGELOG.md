# Changelog

## 1.3.0
- Added configurable durability for supported crafted equipment.
- Added dedicated boots durability handling for the 7 supported craftable boots.
- Added optional Unbreakable mode.
- Added durability multiplier from 1.0x to 1000.0x.
- Cargo, order cargo and cargo containers remain vanilla.
- Simplified/reorganized the public INI.
- Preserved FreeCrafting, 120 configurable entries and craftable Omnireflector Boots from 1.2.0.

## 1.2.0
- Added optional FreeCrafting for all supported recipes.
- Added Omnireflector Boots to normal fabrication.
- Increased configurable entries from 119 to 120.

## 1.0.0
- First public release.
- 119 configurable entries: 90 normal fabrication items, 19 backpack modules, 2 covers and 8 charms.
