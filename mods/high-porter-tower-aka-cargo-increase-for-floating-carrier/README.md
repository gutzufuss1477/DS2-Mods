# High Porter Tower (aka Cargo increase for Floating Carrier)

Expand Level 1 and 2 Floating Carriers to 240 footprint units and a 5,000 kg limit. Native visible stacking is retained, so tall cargo towers can still hit ceilings.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/65)
