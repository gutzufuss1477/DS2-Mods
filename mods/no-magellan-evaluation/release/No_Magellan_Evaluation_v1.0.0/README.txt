No Magellan Evaluation v1.0.0
============================

Removes the Like reward penalty from DHV Magellan deliveries while leaving the original Magellan delivery indicator visible.

Install:
1. Use an external x64 ASI loader for DS2.
2. Copy ds2_no_magellan_evaluation.asi and ds2_no_magellan_evaluation.ini into the DS2 game directory used by the loader.
3. Restart the game.

Validated target: Steam PC build 1.10.89.0.
Debug logging is disabled by default.
