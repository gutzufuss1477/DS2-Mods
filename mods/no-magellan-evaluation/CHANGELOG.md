# Changelog

## 1.0.0

- Initial public release.
- Removes the validated DHV Magellan Like penalty by normalizing the Magellan reward lookup selector to the standard selector.
- Leaves normal deliveries unchanged.
- Leaves the original Magellan delivery indicator visible on the results screen.
- Adds strict Steam `1.10.89.0` build metadata and instruction-signature guards.
- Debug logging is optional and disabled by default.
