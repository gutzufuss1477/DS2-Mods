# Beach Jump with Cargo

Keep backpack and body-mounted cargo through Beach Jumps, Transponder travel and Hot Spring Jumps. Use normal fast-travel controls; vehicles and Floating Carriers are unaffected.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/92)
