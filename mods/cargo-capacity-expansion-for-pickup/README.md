# Cargo Capacity Expansion for Pickup

Expand the Off-road Pickup from 160 to 320 cargo units by default, configurable up to 480. Rear cargo bars scale with the new capacity; the menu percentage still uses vanilla capacity.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/61)
