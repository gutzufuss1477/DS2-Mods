## In-game validation

Visual confirmation was obtained for the experimental v1.0.2 build on 2026-10-10:

- Capacity 320 (200% vanilla menu; 1,508.4 kg): all ten rear segments red, no further cargo fit.
- Capacity 160 of configured 320 (100% vanilla menu; 728.0 kg): five of ten rear segments white.
- The startup status showed both the four cargo-capacity patches and optional rear-indicator detours were active.

The final v1.0.2 release code retains the same display detours and calculations; it changes only metadata, documentation and the success status label. The final release binary has not yet been separately tested in game; other capacities, save/reload and alternative vehicle skins remain follow-up regression cases.
