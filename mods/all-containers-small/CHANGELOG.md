# Changelog

## 1.0.0 — 2026-11-12

First public release of All Containers Small.

- Eligible cargo uses size S, one size unit and matching small-case models.
- Material quantities, item identity and weight fields stay unchanged.
- Functional entities preserve their native resources and models, including the Cart component required during startup.
- Helper processes do not truncate the game's mod log.
- English/German instructions and an optional checked installer are included.
- Author confirmed startup, collection and inventory/backpack results; 17 local checks passed.

This release promotes the confirmed development build 0.1.1. The only runtime change is the version label. The earlier internal 0.1.0 prototype that replaced carrier entities was withdrawn after a startup crash and is not distributed.
