# Safety and scope – Infrastructure One Unit v1.1.0

- The ASI validates the target DS2.exe version using its PE timestamp, image size and required native instruction signatures before installing hooks.
- Unknown game builds fail closed; unsupported executables are not patched.
- Original infrastructure policy remains restricted to approved road, monorail and mine build/upgrade object modes; existing online contributions are preserved through verified transactional progress updates.
- MineProductionCrystalCost=0 is the default and installs **no new mine-production hooks**.
- A positive cost uses **seven precisely matched native hooks**: mine cost getter, production step, production loop increment, transient budget cap, quantity selection, confirmation and the active case-9 menu denominator.
- The actual player crystal wallet, global inventory setters, native material-contribution path, and mine's persistent resource-debit instruction are **not modified**.
- Native cost can only be reduced. The production loop always retains a positive increment. Previously deposited mine resources cannot be converted to unlimited output by the smaller cost.
- A compatible x64 ASI loader is required. Other trainers hooking the same functions may conflict.
- Construction progress can be saved normally by the game. Back up an existing save before first installation.
- In-game verified for cost=1 and the 1/1 display; other values were validated offline but remain to be individually game-tested.
