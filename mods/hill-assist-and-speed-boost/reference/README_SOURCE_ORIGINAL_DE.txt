DS2 Vehicle Physics Core v1.1.0 Source
====================================

Der gemeinsame Core aktiviert Module ausschliesslich über ihre separaten
INI-Dateien:

- VehicleSpeedBoost.ini
- PickupTruckHillAssist.ini

Beide Module verwenden einen einzigen Streaming-Listener. Der Quellcode
entspricht exakt der in den finalen Speed- und Hill-Assist-Paketen enthaltenen
DS2VehicleCore.asi.
