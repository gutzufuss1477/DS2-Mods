[b]What's included[/b]
Vehicle, cargo, equipment, progression, construction and scanning mods — choose only what you want. Install, update, repair or remove with file checks, backups and rollback. Central INI settings retain existing choices and comments.
[b]1.13.0:[/b] Crafting 1.10.1, optional ATLAS addons 1.0.1, Magellan 1.1.0, Gloves 1.1.2 and the unchanged original APAS 3.0.0.

[b]Install / update[/b]
Windows x64 · .NET Framework 4.8 · [b]Steam DS2.exe 1.10.89.0[/b].
[list=1]
[*]Close the game. Download manually and extract the [b]complete ZIP[/b] into its own folder. Keep payload beside the EXE.[/*]
[*]Run [b]DS2ModManager.exe[/b], check the game folder and choose your mods → [b]Apply changes[/b].[/*]
[*]For installed mods: [b]Mod Settings → Save settings → Apply changes[/b]. To update, use the new manager and apply your selection again.[/*]
[/list]
Deselect and apply to remove a mod; personal INIs remain. Do not install through Vortex.

[b]Please read[/b]
[list]
[*][b]APAS:[/b] Unlock All and Early Access default off. Back up your save; saved unlocks can persist.[/*]
[*][b]Crafting / ATLAS:[/b] Addons automatically select Crafting, which must be enabled. First launch can generate large caches. Keep [b]ds2_story_coffin_variants.bin[/b] with save backups. Keep the main mod installed while using custom equipment; see the [url=https://www.nexusmods.com/deathstranding2onthebeach/mods/86]standalone instructions[/url].[/*]
[*][b]Backpack:[/b] Choose one variant. Before removal, unequip extra charms, restore a vanilla layout and save. Classic Overlap remains untested in game.[/*]
[*]Follow conflict warnings before applying. Current file scan status is shown in the [b]Files[/b] tab.[/*]
[/list]
[b]Languages:[/b] English, German, French, Spanish, Italian, Brazilian Portuguese, Russian, Simplified Chinese, Japanese and Korean.
