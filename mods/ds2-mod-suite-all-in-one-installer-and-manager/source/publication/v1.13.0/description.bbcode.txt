[b]Features[/b]
Install, update, repair or remove DS2 mods with file checks, backups and rollback. Central INI settings preserve existing choices and comments. Works offline. Pick only what you want; choose one Backpack variant.

[b]Prepared in 1.13.0[/b]
Crafting 1.10.1, optional ATLAS appearance addons 1.0.1, Magellan 1.1.0 and Climbing/Combat Gloves 1.1.2. ATLAS addons select their required Crafting mod automatically. New Warrior, guitar, cosmetics and Magellan options are translated into all ten interface languages.

[b]Install / update[/b]
Windows x64 · .NET Framework 4.8 · [b]Steam DS2.exe 1.10.89.0[/b].
[list=1]
[*]Close the game. Download manually and extract the [b]complete ZIP[/b] into its own folder, keeping payload beside the EXE. Do not install through Vortex.[/*]
[*]Run [b]DS2ModManager.exe[/b], check the game folder, select mods → [b]Apply changes[/b].[/*]
[*]For installed mods: [b]Mod Settings → Save settings → Apply changes[/b]. Deselect and apply to remove; personal INIs remain.[/*]
[/list]

[b]Keep your data[/b]
Before removing Backpack, unequip extra charms, restore a vanilla layout and save. Classic Overlap remains untested in game. For Crafting, keep [b]ds2_story_coffin_variants.bin[/b] with save backups and retain the main mod while using custom equipment. First launch can generate large caches. See the [url=https://www.nexusmods.com/deathstranding2onthebeach/mods/86]Crafting instructions[/url].
