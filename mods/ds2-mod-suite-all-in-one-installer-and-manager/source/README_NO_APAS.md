# DS2 Mod Suite 1.13.0 — without APAS

This comparison build contains the same manager and updates as 1.13.0, excluding APAS. Existing standalone APAS files remain untouched. It is not a guarantee of antivirus acceptance.

Extract the entire ZIP including payload. Close the game, run DS2ModManager.exe, select DS2.exe and apply the desired selection. Existing INI choices are retained.

Includes Crafting 1.10.1, optional ATLAS addons 1.0.1, Magellan 1.1.0 and Gloves 1.1.2. ATLAS addons require enabled Crafting. Keep ds2_story_coffin_variants.bin with save backups. Crafting generates substantial local caches; keep custom-equipment mods installed while using their items.

Source and full installation notes: https://github.com/gutzufuss1477/DS2-Mods
Downloads: https://www.nexusmods.com/deathstranding2onthebeach/mods/72
