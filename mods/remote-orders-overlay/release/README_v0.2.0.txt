DS2 Remote Orders Overlay v0.2.0
================================

Supported game: DEATH STRANDING 2: ON THE BEACH, Steam DS2.exe v1.10.89.0

Installation
------------
1. Close the game.
2. Install one working x64 ASI loader beside DS2.exe.
3. Remove every older Remote Orders Overlay ASI.
4. Copy DS2_Remote_Orders_Overlay.asi and DS2_Remote_Orders_Overlay.ini beside DS2.exe.
5. Start the game and open the world map.

Localization
------------
Language=auto uses the Windows display language. If the game uses another language,
set Language explicitly in DS2_Remote_Orders_Overlay.ini.

Supported codes:
en, fr, it, de, es-ES, es-419, pt-BR, pt-PT, ar, cs, nl, el, ja, ko, pl, ru,
zh-Hans and zh-Hant.

The overlay reads order data and native localized destination names from the game.
It does not accept orders or intentionally modify missions, saves or facility state.

Known limitation
----------------
A small number of Romance-language facility names may retain an extra grammatical
article before the label is shortened to fit the overlay column.
