# Changelog

## v0.2.0

- Localized the overlay UI for all 18 Steam interface languages.
- Added `DS2_Remote_Orders_Overlay.ini` with automatic Windows-language selection and an explicit language override.
- Preserved native game localization for mission destinations and facility names.
- Added language-aware removal of repeated native facility-name variants.
- Added right-to-left layout support for Arabic and ellipsis handling for long localized labels.
- Promoted the source-compiled build after successful in-game smoke tests in German, French, Italian and Spanish.

## v0.1.3-alpha

- Published the runtime-tested compact Remote Orders overlay.
- Disabled all persistent diagnostic log files.
- Preserved the validated executable code and DS2 runtime logic unchanged.
- Added full recovered source, transparent release-reproduction script and security documentation.
- Marked the unsuccessful source-cleanup build as withdrawn and excluded it from the repository.
