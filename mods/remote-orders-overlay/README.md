# Remote Orders Overlay

See relevant available orders by hovering over a facility on the world map. A read-only overlay with up to ten orders, localized names and an INI language override.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/59)
