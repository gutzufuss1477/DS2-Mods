# Construction Max Level On Build

Automatically raise newly built player PCC structures to their maximum level without extra upgrade materials. Saved upgrades persist; online structures and world infrastructure are unaffected.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/deathstranding2onthebeach/mods/74)
